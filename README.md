# КТК ЭЛОУ-АВТ

Учебный тренажёр технологического процесса ЭЛОУ-АВТ с двумя ролями, интерактивной моделью установки, оценкой действий оператора и прогнозом параметров.

**Демо:** [https://tutor.kluknulo.ru/login](https://tutor.kluknulo.ru/login)
**Дедлайн конкурсной сдачи:** 11 августа 2026 года

Демо-учётные записи используют общий учебный пароль `Ktk_2026!`:

| Роль | Логин |
|---|---|
| Инструктор | `instructor_1` |
| Оператор | `operator_1` |
| Оператор | `operator_2` |
| Оператор | `operator_3` |
| Оператор | `operator_4` |
| Оператор | `operator_5` |
| Оператор | `operator_6` |
| Оператор | `operator_7` |

Роль в форме входа должна совпадать с ролью учётной записи. Эти локальные
учётные записи предназначены только для конкурсного стенда. В промышленном
контуре аутентификация должна быть передана корпоративной службе каталогов
ALD Pro/LDAP/SSO: сотрудники входят под персональными корпоративными учётными
записями, а локальные демо-пользователи отключаются.

## Что реализовано

- сквозной учебный маршрут ЭЛОУ → АТ → ВТ;
- детальная модель контура П-1/К-1 и агрегированные модели ЭЛОУ и ВТ;
- семь учебных сценариев и девять отказов для инструктора;
- отдельные интерфейсы оператора и инструктора;
- WebSocket-телеметрия с шагом симуляции 1 секунда;
- журнал действий, завершение сессии и ScoreCard;
- ONNX LSTM: прогноз трёх технологических параметров на горизонт 15 секунд;
- гибридный расчёт риска: ONNX-прогноз, численный baseline и технологические правила;
- локальный поиск по базе знаний и подсказки с указанием источника;
- JWT, RBAC, ограничение частоты команд, HMAC-SHA256 и цепочка аудита.

## Границы MVP

Это образовательный прототип, а не промышленный цифровой двойник и не система
управления установкой. Физическая модель ещё не калибрована по реальной
телеметрии. ML-модель обучена на синтетических данных; текущая оценка
подтверждает работу контура, но не промышленную точность. Решение о допуске
сотрудника принимает инструктор.

Контур ЭЛОУ представлен агрегированно: модель показывает изменение содержания
солей и воды, подачу деэмульгатора и отказ обессоливания, но не моделирует
электроды, высоковольтные источники ИПМ и автоматическое снятие напряжения при
уровне нефти ниже 3500 мм. Эта блокировка остаётся обязательным требованием
реальной установки и должна быть реализована при детализации модели ЭЛОУ.

Вакуумный блок К-2 также является упрощённой учебной моделью. В ней
рассчитываются уровень куба, остаточное давление и температура низа колонны,
поскольку эти параметры нужны для сценариев срыва вакуума и отказа насосов
Н-4/Н-32. Начальные и динамические значения К-2 требуют калибровки по реальной
телеметрии и не являются паспортными показателями промышленной установки.

## Быстрый старт

Требуется Node `^20.19` или `>=22.12`, Python 3.11+ и Docker Compose.

### Docker Compose

```bash
cp backend/.env.example backend/.env
docker compose up --build
```

| Сервис | Адрес |
|---|---|
| Интерфейс | http://localhost:8080/ |
| API | http://localhost:8000/ |
| Health | http://localhost:8000/api/health |

### Раздельный запуск

```bash
pip install -e backend
cp backend/.env.example backend/.env
python -m uvicorn elou_tutor.api.main:app --host 127.0.0.1 --port 8000 --reload
npm install --prefix frontend
npm run dev --prefix frontend
```

Frontend: http://localhost:5173/
Backend: http://127.0.0.1:8000/
