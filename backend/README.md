# КТК ЭЛОУ-АВТ — Backend API

API-сервер реального времени для связи веб-интерфейса тренажера с физико-математическим симулятором процессов ЭЛОУ-АВТ и ИИ-модулем оценки оператора.

---

## 🎯 Стек технологий

* **Python 3.11+** — среда выполнения.
* **FastAPI** — веб-фреймворк для REST API и WebSocket.
* **Uvicorn** — ASGI-сервер.
* **SQLite3** — легкая встроенная база данных для хранения результатов сессий и журналов ИБ.
* **ONNX Runtime** — выполнение инференса нейросети RiskLSTM в реальном времени.

---

## 📂 Модульная структура бэкенда

Бэкенд строго следует стандартам модульности и безопасности проекта:

```text
backend/src/elou_tutor/
├── api/                       # FastAPI, Pydantic, REST и WebSocket
│   └── routes/                # auth, sessions, scenarios, health, AI и WS
├── services/                  # Сессии, соединения, цикл симуляции и RAG
├── simulation/                # Физическая модель П-1/К-1, К-2 и сценарии
├── tutor/                     # LCS, анализ ошибок и рекомендации
├── ml/                        # ONNX-инференс и проверка артефактов
├── domain/                    # Технологические пределы, регламенты и целостность
├── db/                        # SQLite, запросы и защищённый аудит
├── data/                      # Встроенный реестр сценариев
└── knowledge_base/            # Локальная база знаний по регламентам
```

---

## 🔒 Безопасность и контроль целостности (К8: ИБ)

1. **Защита от НСД**: Доступ к истории тренировок разграничен.
2. **Контроль целостности записей**: Каждая сессия в таблице `training_sessions` подписывается HMAC-SHA256 с секретом окружения, включающим время, оценку, ошибки и полные логи действий оператора. Изменение записи напрямую в БД выявляется при чтении API.
3. **Журнал аудита**: Значимые события (авторизация, управление задвижками, инъекция дефектов, сброс истории) записываются в `audit_logs`, связанные последовательной хэш-цепочкой. Изменение или удаление промежуточной записи нарушает проверку цепочки.

## 🚀 Быстрый запуск

### 1. Установка зависимостей

Из каталога `backend/` установите runtime и инструменты проверки:

```bash
python -m pip install -r requirements-dev.txt
cp .env.example .env
```

Переобучение модели вынесено из runtime в каталог `ml_training/` и использует
собственный файл зависимостей.

### 2. Запуск локального сервера разработки
Запустите сервер с авто-перезагрузкой:
```bash
python -m uvicorn elou_tutor.api.main:app --host 127.0.0.1 --port 8000 --reload
```
API документация Swagger/OpenAPI будет доступна по адресу: `http://localhost:8000/docs`

### 🧪 Запуск тестов
Запустите набор юнит- и интеграционных тестов:
```bash
python -m pytest tests/ -q
ruff check .
lint-imports
```

Тесты используют временные изолированные базы данных и не изменяют рабочую
историю тренировок.
