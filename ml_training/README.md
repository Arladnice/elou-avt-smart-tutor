# Офлайн-пайплайн обучения модели риска

Здесь живёт всё, что нужно, чтобы получить `model.onnx` — модель, которая в рантайме прогнозирует технологические параметры на 15 секунд вперёд и считает уровень риска.

**Этот каталог не входит в прод-образ.** Обучение требует PyTorch (сотни мегабайт), а рантайму достаточно `onnxruntime`. Поэтому `ml_training` перечислен в `.dockerignore`, а Dockerfile копирует только `backend/src`. Тест `backend/tests/test_training_isolation.py` следит за тем, чтобы пакет `elou_tutor` никогда не начал импортировать этот каталог.

## Почему гиперпараметры не лежат здесь

Архитектура сети и нормировка входа/выхода берутся из **установленного пакета** — `elou_tutor.ml.settings`. Это единственный способ гарантировать, что обучение и инференс не разъедутся: правка `HIDDEN_DIM` или `SCALER_MAX` автоматически действует на обе стороны. В локальном `config.py` остаётся только то, что рантайму не нужно вовсе: пути к артефактам, скорость обучения, число эпох, разбиение выборки.

## Установка

```bash
pip install -e backend
pip install -r ml_training/requirements.txt
```

Первая команда ставит runtime-пакет, поэтому `elou_tutor.ml.settings` доступен офлайн-пайплайну. Вторая ставит только инструменты обучения: torch, onnx, scikit-learn, pandas и matplotlib.

## Порядок запуска

Скрипты запускаются из корня репозитория и рассчитаны на выполнение по цепочке:

```bash
python ml_training/data_generator.py   # 1. синтетическая телеметрия из симулятора
python ml_training/train.py            # 2. обучение LSTM
python ml_training/export_onnx.py      # 3. экспорт в ONNX
python ml_training/evaluate.py         # 4. честная оценка на отложенной выборке
```

`baselines.py` — вспомогательный: считает тривиальные базовые решения, с которыми сравнивается модель. Запускается независимо.

## Куда попадают артефакты

| Что | Куда |
|---|---|
| Датасет телеметрии, отложенная выборка | `data/` |
| Чекпоинт PyTorch (`lstm_model.pth`) | `checkpoints/` |
| Отчёт об оценке | `reports/evaluation_report.md` |
| **Модель для рантайма (`model.onnx`)** | **`backend/src/elou_tutor/ml/artifacts/`** |

Последняя строка важна: `export_onnx.py` кладёт модель не рядом с собой, а сразу внутрь пакета — туда, где её ищет `RiskPredictor`, и откуда она попадает в образ как package data. Путь берётся из `elou_tutor.ml.settings.ONNX_PATH`, а не задаётся здесь.

## Честность оценки

`evaluate.py` оценивает чистую ONNX LSTM по MAE/RMSE/R² отдельно от гибридного risk engine. Для риска отчёт показывает матрицу ошибок и событийный lead time; горизонт прогноза не подменяется измеренным упреждением. Датасет имеет фиксированный seed, версию и SHA-256 в `telemetry_dataset.csv.metadata.json`. Калибровка на реальной архивной телеметрии остаётся задачей пилота.
