Основным вычислительным элементом инфраструктуры является сервер. Сервер — это устройство или экземпляр ПО. Почему так это делится? Потому что, когда мы говорим «сервер», он может быть физический, может быть виртуальным.

Мы переходим к конструктивным характеристикам. Какие есть форматы? Есть форматы PCI, есть форматы SXM. PCI есть однослотовый и двуслотовый.

Однослотовый — это для карточек с низким энергопотреблением. Какие есть интерфейсы подключения? Связь с CPU через PCI. Если говорить про интерконект, связь с GPU-GPU, есть технология NVLink.

Не все PCI-карты поддерживают NVLink. Для того, чтобы их соединить, то есть объединить память нескольких GPU в одно, можно использовать мосты, как показаны на картинке. Для SXM-модулей также есть еще технология NVSwitch.

Тогда мы соединяем все карты со всеми картами. А вот NVLink позволяет соединить только попарно. Есть такой параметр TDP, как расчет на тепловая мощность. Есть карточки слабые, есть карточки помощнее, которые будут выделять уже больше тепла. Если речь про SXM-модули, то они значительно сильнее нагреваются, чем PCI-карты.

И когда все это вставляется в сервер, надо обеспечить хорошее охлаждение. Внизу приведена картинка с сервером, как расположены там карты. То есть на пути воздуха нет никаких горячих элементов, нет никаких лишних проводов, чтобы воздух холодный проходил через сервер и максимально отводил тепло от горячих карт.

Есть такая технология, как DLC — прямое жидкостное охлаждение. Есть карты, которые уже с завода выходят с жидкостным охлаждением, занимают они при этом вместо двух слотов один слот. Это позволяет намного больше карт в сервер вставить.

Есть специальные водоблоки. Это такая интересная конструкция. Сначала берется обычный PCI-модуль, снимается воздушный охлаждение, достается оттуда PCI-плата, это вставляется в водоблок, и все это вставляется, тоже отводит тепло.
