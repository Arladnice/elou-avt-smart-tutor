## 📌 Ключевые архитектурные выводы для КТК ЭЛОУ-АВТ

1. **Формула ИИ-Агента в бэкенде:**
   $$\text{Agent} = \text{LLM} + \text{Tools (API симулятора)} + \text{ReAct Loop} + \text{RAG Память} + \text{Guardrails}$$

2. **Защита от галлюцинаций (Grounding):**
   Все рекомендации ИИ-консультанта оператору обязаны проходить через **Guardrails** и RAG по оцифрованному технологическому регламенту ЭЛОУ-АВТ (`docs/equipment_specification.md`).

3. **Human-in-the-Loop:**
   ИИ не ставит финальную оценку единолично — он подготавливает мотивированный протокол с деталями нарушений, а финальное решение о допуске остается за Инструктором.
