## 📌 Защитные аргументы для критериев К1, К3, К4, К6

1. **Соответствие мировому стандарту IIBA (К6):**
   Вся документация требований и архитектура проекта опираются на официальный международный стандарт **BABOK® v3.0**, включая модель концептов BACCM™ и трассировку требований.

2. **Строгая классификация требований (К1):**
   - *Business:* Сокращение аварийности на НПЗ на 8%+, окупаемость КТ.
   - *Stakeholder:* Разделение рабочих столов Оператор / Инструктор.
   - *Functional:* ИИ-анализ траекторий (DTW), предиктивный инференс ONNX, RAG-объяснение по регламенту.
   - *Non-Functional:* Задержка WebSocket < 100мс, время отклика UI < 200мс, SHA-256 HMAC подпись логов аудита.

3. **Многомерный финансовый анализ (К4):**
   Обоснование экономической ценности решения выполнено по методологии раздела 10.20 BABOK v3 (NPV, ROI, TCO, DPP).
