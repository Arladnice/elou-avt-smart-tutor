# 🏛 Документация проекта КТК ЭЛОУ-АВТ Smart Tutor

В данном каталоге собраны отчетные, проектные и справочные материалы по разработке Компьютерного тренажерного комплекса (КТК) первичной переработки нефти ЭЛОУ-АВТ в соответствии с 8 критериями оценки кейса.

---

## 📂 Структура каталога

### 🧭 Для разработчиков
*   **[architecture.md](architecture.md)** — Архитектура проекта: слои пакета `elou_tutor`, FSD-фронтенд, контракт WS/REST, конвенции кода и инструкция «куда класть новый функционал». **Начните отсюда, если дорабатываете проект.**
*   **[../backend/training/README.md](../backend/training/README.md)** — Офлайн-пайплайн обучения LSTM: генерация датасета, обучение, экспорт в ONNX, честная оценка.
*   **[deploy/README_HF.md](deploy/README_HF.md)** — Развёртывание одноконтейнерного образа на Hugging Face Spaces и Render.
*   **[deploy/caddy.md](deploy/caddy.md)** — Публикация стека на боевом хосте за фронт-прокси Caddy: HTTPS, домен, WebSocket.

### 📄 Основные проектные документы (Разделы для сдачи)
*   **[main_strategic_plan.md](main_strategic_plan.md)** — Главный стратегический план команды. Содержит GAP-анализ по 8 критериям оценки, план спринтов и чек-лист готовности проекта.
*   **[solution_architecture.md](solution_architecture.md)** — Архитектура IT-решения (по модели 4+1, диаграммы интеграции, процесса, логики и развертывания).
*   **[ai_architecture.md](ai_architecture.md)** — Архитектура ИИ-модуля (детализация LSTM-прогноза рисков и LCS-анализа ошибок).
*   **[infrastructure.md](infrastructure.md)** — Инфраструктурное решение (аппаратные требования, резервирование, latency-контроль, мониторинг Prometheus+Grafana).
*   **[requirements.md](requirements.md)** — Техническое задание (БТ, ФТТ, НФТ по ГОСТ 34.602-89).
*   **[economics.md](economics.md)** — Финансово-экономическое обоснование (TCO, NPV, PI, IRR, DPP, дерево КПЭ).
*   **[market_analysis.md](market_analysis.md)** — Анализ рынка, сравнение существующих OTS-решений и конкурентные преимущества.
*   **[legal_compliance.md](legal_compliance.md)** — Регуляторное соответствие (Ростехнадзор, ГОСТ, ФЗ-152) и лицензионная чистота.
*   **[security_threat_model.md](security_threat_model.md)** — Модель угроз ИБ (RBAC, криптографический аудит результатов).

### 🎤 Материалы защиты
*   **[presentations/ELOU_AVT_Smart_Tutor.pptx](presentations/ELOU_AVT_Smart_Tutor.pptx)** — Презентация для отборочного этапа (10 слайдов по 8 критериям оценки, с заметками докладчика на каждом слайде).
*   **[presentation_content.md](presentation_content.md)** — Текстовая структура презентации (исходник для правок).

### 📊 Технологические спецификации и тесты
*   **[equipment_specification.md](equipment_specification.md)** — Оцифрованная спецификация КИПиА и технологических ограничений установки ЭЛОУ-АВТ.
*   **[manual_testing_checklist.md](manual_testing_checklist.md)** — Чек-лист ручного функционального тестирования сценариев и дефектов.

### 📚 Справочные материалы
*   **[reference/](reference/)** — Сырые материалы вебинаров, расшифровки комментариев спикеров, ответы экспертов Газпромнефти, текст презентации кейса, а также матрицы команды (`competency_matrix.csv`, `roles_matrix.csv`) и справка по симулятору (`simulation.md`).

*   **[tools/convert_docs.py](tools/convert_docs.py)** — Разовая конвертация исходных материалов. Содержит жёстко зашитый путь к машине автора и вне её неработоспособен.
