# Model card: RiskLSTM

## Назначение

RiskLSTM прогнозирует температуру печи П-1, давление и уровень колонны на 15 секунд вперёд по окну телеметрии `30×7`. Образовательный risk engine использует прогноз температуры для раннего предупреждения о входе в предаварийную зону П-1 — `T-1 ≥ 350 °C`.

Модель не управляет оборудованием. ПАЗ и аварийный останов остаются детерминированными функциями симулятора.

## Версия и артефакты

| Поле | Значение |
|---|---|
| Модель | `risk-lstm-2026-08-08-v2` |
| Архитектура | LSTM: 2 слоя, hidden size 64, dropout 0,2 |
| Вход | 30 секунд × 7 признаков |
| Выход | `T-1`, `P-1`, `L-1` через 15 секунд |
| Runtime | ONNX Runtime, CPU |
| Целостность | SHA-256 для `model.onnx` и `model.onnx.data` в `model.manifest.json` |
| Fallback | Линейная экстраполяция только при недоступности или нарушении целостности ONNX |

## Метрики

Отложенный test split содержит 9 864 окна и 99 будущих входов в предаварийную температурную зону. Полная методика и хэш данных — в `ml_training/reports/evaluation_report.md`.

| Показатель | ONNX LSTM | Persistence baseline |
|---|---:|---:|
| MAE T-1, °C | 5,38 | 14,14 |
| MAE P-1, МПа | 0,0108 | 0,0221 |
| MAE L-1, п.п. | 0,67 | 1,32 |
| R² T-1 / P-1 / L-1 | 0,985 / 0,969 / 0,993 | 0,916 / 0,856 / 0,980 |

Для предаварийного перегрева П-1 risk engine дал Precision 0,823, Recall 0,657 и F1 0,730. Измеренное медианное упреждение для событий, где alert возник до входа в зону, — 17 секунд. Это результат на синтетических данных, не показатель промышленной точности.

## Ограничения

- Данные синтетические; переносимость на реальную установку не подтверждена.
- Метрика риска относится к перегреву П-1. Давление и уровни пока защищаются ПАЗ и технологическими правилами.
- Модель не должна использоваться для автоматического управления, отключения защит или производственных решений.
- При ошибке проверки хэша или загрузки ONNX интерфейс получает результат fallback, а журнал приложения фиксирует проблему.
