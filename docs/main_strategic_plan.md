# План доведения до конкурсной сдачи

**Дедлайн:** 11 августа 2026 года
**Стенд:** [https://tutor.kluknulo.ru/login](https://tutor.kluknulo.ru/login)
**Правило:** до сдачи не расширять функционал, пока не закрыты демо, доказательства и противоречия в материалах.

## 3 августа — единая версия проекта

- [ ] Зафиксировать один сценарий демонстрации и пройти его три раза.
- [ ] Обновить PPTX: URL, семь сценариев, актуальные тесты, честные AI/ML-ограничения.
- [ ] Удалить старые аудиты, планы и текстовые черновики презентации.
- [ ] Привести README, документацию и речь к одной версии фактов.
- [ ] Проверить frontend build и полный Docker-запуск на машине демонстрации.
- [ ] Записать резервное видеодемо.

## 4 августа — трассировка и предметная проверка

- [ ] Связать восемь критериев с функциями, экранами, тестами и доказательствами.
- [ ] Проверить с технологом обозначения оборудования, пороги, единицы и действия сценариев.
- [ ] Проверить нормативные цитаты базы знаний по исходным документам.
- [ ] Пометить текущую и целевую архитектуру во всех документах.

## 5 августа — AI/ML без преувеличений

- [ ] Выпустить model/data card: синтетические данные, split, метрики и ограничения.
- [ ] Зафиксировать версию и hash модели/датасета.
- [ ] Объяснить precision 2,67%, recall 100% и выбор консервативного порога.
- [ ] Не использовать формулировки о промышленной точности до реальной валидации.

## 6 августа — инфраструктура и безопасность

- [ ] Перенести deploy credentials из GitHub Variables в Secrets.
- [ ] Проверить сборку, healthcheck, restart и сохранение сессий.
- [ ] Выполнить лёгкий тест параллельных сессий и записать условия измерения.
- [ ] Проверить отсутствие секретов и персональных данных в репозитории и видео.

## 7 августа — экономика и рынок

- [ ] Для каждой переменной экономики указать источник или пометку «гипотеза».
- [ ] Добавить sensitivity ±20%.
- [ ] Проверить конкурентные сравнения по первичным источникам.
- [ ] Убрать утверждение об исторических данных.

## 8 августа — сборка конкурсного пакета

- [ ] Финальные PPTX и PDF.
- [ ] Короткая пояснительная записка.
- [ ] MP4 с рабочим сценарием.
- [ ] Ссылка на репозиторий/commit и evidence pack.

## 9 августа — репетиция

- [ ] Три защиты с таймером.
- [ ] Вопросы о границах MVP, синтетике, precision, безопасности и экономике.
- [ ] Проверка отказа сети и перехода на резерв.

## 10 августа — freeze

- [ ] Только исправление блокирующих дефектов.
- [ ] Чистая сборка из клона/архива.
- [ ] Проверка всех ссылок, файлов, логинов и звука.
- [ ] Контрольные суммы финальных артефактов.

## 11 августа — сдача

- [ ] Загрузить материалы заранее, не в последние минуты.
- [ ] Скачать или открыть загруженные файлы для проверки.
- [ ] Сохранить подтверждение приёма.

## Критерий готовности

Пакет готов, если новый человек может открыть README, запустить проект по инструкции, пройти сценарий без подсказки разработчика и повторить заявленные проверки. Любой численный тезис в презентации должен иметь файл, лог или источник.
