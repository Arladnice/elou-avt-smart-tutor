## Обнаруженные риски

### Высокий приоритет перед записью

1. Визуальный путь не подтверждён автоматикой: необходимо проверить переполнение, масштаб, модальные окна, графики и PDF в браузере, который будет использоваться для записи.
2. Старый `docs/manual_testing_checklist.md` частично устарел: в нём встречаются произвольные имена пользователей, тогда как текущая система требует предсозданные учётные записи и пароль. Для записи использовать актуальные данные из README и нового видеоплана.

### Не блокирует запись

1. В pytest остаются два предупреждения: deprecation адаптера `httpx` и намеренно короткий чужой JWT-ключ в негативном тесте.
2. Vite предупреждает о крупном основном bundle. Сборка проходит; для демонстрации важнее предварительно прогреть страницу.
3. Публичный WS имел единичный выброс 252,98 мс при p95 11,84 мс. Перед записью стоит обновить страницу и проверить стабильный ping.
4. Экономика и улучшение навыков остаются гипотезами до пилота; в речи нельзя подавать их как измеренный эффект.

## Решение о записи

**Условно готово.** После успешного визуального UAT всех десяти критических пунктов можно записывать финальное видео. Если хотя бы один из пунктов входа, двух ролей, realtime, дефекта, ScoreCard или истории не проходит, сначала устранить проблему и повторить контрольный прогон.
